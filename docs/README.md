# Documentation

This directory holds the project's guides. Domain terminology is defined in
[`CONTEXT.md`](../CONTEXT.md) and must be used consistently in code, tests, and
docs.

## Current guides

- [Development](./development.md) — workspace layout, commands, the golden-tour
  workflow, and the TypeScript 7 constraints.
- [Repository analysis](./analysis.md) — read-only snapshots, symbols, cache,
  the CLI, and the project brief.
- [Tour authoring](./authoring.md) — the authoring pipeline, models, quality
  reports, and the author CLI.
- [Player and code browser](./player.md) — playback controls, keyboard map,
  virtualized code pages, stale badges, and progress.

## Planned guides

Phase plans add per-area guides as the behavior ships: `architecture.md`,
`authoring.md`, `tour-format.md`, `player.md`, `narration.md`,
`opencode-plugin.md`, `self-hosting.md`, `privacy.md`, `accessibility.md`, and
`troubleshooting.md`.
