# Documentation

This directory holds the project's guides. Domain terminology is defined in
[`CONTEXT.md`](../CONTEXT.md) and must be used consistently in code, tests, and
docs.

## Current guides

- [Development](./development.md) — workspace layout, commands, the golden-tour
  workflow, and the TypeScript 7 constraints.
- [Architecture](./architecture.md) — packages, pipeline, trust boundaries, and
  storage.
- [Tour format](./tour-format.md) — the document, anchors, diagrams, and
  versioning.
- [Repository analysis](./analysis.md) — read-only snapshots, symbols, cache,
  the CLI, and the project brief.
- [Tour authoring](./authoring.md) — the authoring pipeline, models, quality
  reports, and the author CLI.
- [Player and code browser](./player.md) — playback controls, keyboard map,
  virtualized code pages, stale badges, and progress.
- [Narration](./narration.md) — browser and cloud speech, synchronization,
  caching, and privacy.
- [Guide and interludes](./guide.md) — in-tour questions, citations, drilldown,
  and progress.
- [OpenCode plugin](./opencode-plugin.md) — install, commands, tools, RPC, and
  the host model adapter.
- [Harnesses](./harnesses.md) — the `HarnessAdapter` contract, the shared
  runtime, and the Claude Code and Codex adapters.
- [Settings](./settings.md) — connection profiles, the secret store, and
  resolution rules.
- [GitHub import](./import.md) — URL forms, sandbox limits, and the import
  API/UI/CLI.
- [Accounts and sync](./accounts.md) — GitHub OAuth, sessions, merge rules,
  export, and delete.
- [Embeddable player](./embed.md) — export, the host API, progress, CSP, and
  the docs fixture.
- [Human review](./review.md) — the review state machine, editing, regeneration,
  anchor gating, and decisions.
- [Self-hosting](./self-hosting.md) — install, serve, environment, storage, and
  upgrades.
- [Privacy](./privacy.md) — what stays local and what cloud choices send.
- [Accessibility](./accessibility.md) — the axe gate, keyboard map, and known
  gaps.
- [Troubleshooting](./troubleshooting.md) — common local runtime failures.
- [Release notes](./release-notes.md) — the first local-first release and its
  known limitations.
