## Priorities

1. **High · correct source binding.** The current project record uses the project
   slug as its storage key. Define a local identity and revision binding and
   verify two same-name checkouts at the authoring and source interfaces. [#11](https://github.com/anthonyclarka2/sothspell/issues/11)
2. **High · keyboard and screen-reader access.** Close the known keyboard and
   equivalent-content gaps and evaluate the complete journeys with assistive
   technology. [#7](https://github.com/anthonyclarka2/sothspell/issues/7)
3. **High · stale and failed tour reads.** Two Hono regressions reproduced a
   stale title after atomic replacement and a persistent failure after a
   missing file became available. Source loads now read the current artifact
   before reusing the one retained compile, and a rejected compile clears that
   entry. Translation remains sensitive to the current translation store.
4. **Medium · bundle and runtime baseline.** The production entry chunk was
   844.68 kB minified and 246.63 kB gzip. Generated source-map attribution puts
   React DOM, React Flow, icon code and routing among the major dependency
   contributors. The bundle checker cannot currently measure the Canvas and
   image-export budgets independently. Seven loopback production Chromium
   navigations to the first playable beat took 855 ms with a cold server and
   131–168 ms with a warm server. Every navigation used a fresh browser context.
   Use a representative network profile before choosing a splitting budget.
5. **Medium · dependency maintenance.** Recheck production advisories and
   update affected dependencies as compatible fixed releases become available.
   The existing CI high-severity gate passed. Follow the private reporting path
   in [SECURITY.md](../SECURITY.md) for unpublished vulnerabilities.
