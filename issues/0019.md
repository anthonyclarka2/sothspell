# "Canvas: resize, move, close, and select containers and objects"

"The first canvas shipped with a deterministic, read-only board. Viewers need
direct manipulation: resize code containers, move cards by their headers, close
containers and reopen them from their object, select diagram objects, and see
connected edges highlighted. Fullscreen should re-fit the board to the new
viewport. Code lines also show blank-line gaps from Shiki's preserved newlines."

---

## Update 1 — implementation (2026-10-21)

"Implemented on `phase-21-canvas-interactions`:

- Code containers use React Flow `NodeResizer` with a 280×180 minimum and store
  manual sizes in view state.
- Code and diagram cards drag by their headers; manual positions override the
  deterministic layout until auto-arrange/reset.
- Code headers have a close button; closed containers are filtered from the
  scene and reopen from their diagram object or relation toggle.
- Selecting a card highlights its border and connected evidence/flow edges.
- Diagram objects are selectable even without a code target; an unresolved
  object announces the missing code instead of being disabled.
- Entering fullscreen re-fits and centres the board after the viewport resize.
- `shikiHtmlForCanvas` strips Shiki's inter-line whitespace, removing the
  blank-line gaps while preserving line height.
- Compact and outline views expose the close action.

Tests: 7 new canvas-interaction Playwright journeys, code HTML gap test, full
unit suite and full browser/a11y suite; Bunbun remains read-only."
