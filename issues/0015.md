# "Canvas: compact layout below 768 px and touch support"

"A spatial canvas does not fit a phone. Below 768 px the canvas should become a
vertical reading layout with the same diagram, code containers, relationship
text, and actions. Touch needs pan, pinch zoom, and 44 px targets; every drag
action needs a visible alternative."
