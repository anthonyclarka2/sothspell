# "Canvas: screen-reader outline and live announcements"

"A spatial board is not understandable to a screen reader by itself. The canvas
needs a semantic text equivalent that lists diagrams, objects, code containers,
relationships, and actions in reading order, plus a live region for state
changes. Axe cannot prove this; manual VoiceOver checks are required, with NVDA
owner-gated on Windows."
