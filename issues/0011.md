# "Canvas: keyboard navigation with one tab stop"

"The canvas must be fully operable without a pointer. Arrow keys and HJKL move
selection between containers; Enter enters a container; arrows move inside it;
Enter activates; Escape exits fullscreen first when active, then steps item ->
container -> home diagram. React Flow's default arrow-key node movement conflicts
with this model, and the player's global Space/arrow/T/Escape shortcuts conflict
too."

---
