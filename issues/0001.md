# "Canvas: build the pure scene and deterministic layout model"

"The canvas needs one pure model that turns a compiled tour plus a beat into
diagram cards, code containers, evidence slots, selection, and viewport math.
The React layer must not own layout decisions, and the same tour/beat/viewport
must always produce the same arrangement. This is the foundation for every
other canvas feature."

---

## Update 1 — plan (2026-10-21)

"Planned as Phase 17 Wave 1 in `plans/PHASE-17.md`. New `packages/canvas` with
`buildCanvasScene`, a synchronous deterministic `layoutCanvas`, `viewportFor`,
and a selection reducer. Auto-arrange is a separate async command that may use
ELK. No React, DOM, or filesystem. Tests cover deterministic output, no overlap,
home centering, bounds, zoom clamps, empty scenes, and multi-anchor scenes."
