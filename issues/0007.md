# "Generated tours put symbol IDs in diagram node anchor IDs, so diagram clicks dead-end"

"`assembleDocument` gives each beat anchor a normalized ID such as
`beat_..._anchor_1`, but it copies the model's candidate ID such as
`symbol:src/app.module.ts#AppModule` into each diagram node's `anchorId`. The
golden tour works because it was hand-built with matching anchor IDs; generated
tours have diagram nodes that cannot open their cited code. The canvas makes
this visible because clicking an object should open a container."
