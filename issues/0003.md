# "Canvas: open code from a diagram object and draw the evidence line"

"Clicking a decision shape or object in the diagram must open a code container
with the cited excerpt and draw a line to the anchor's start line or cited range.
The current stage navigates to a code page instead, and generated tours cannot
resolve their diagram targets. The canvas needs object-level ports and one
evidence link per citation."
