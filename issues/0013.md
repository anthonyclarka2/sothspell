# "Canvas: auto-zoom and auto-arrange preferences with undo and first-run explanations"

"Opening a new container should frame it with its source, and the board should
arrange itself when a container opens. Both behaviours must be user
preferences. The first use needs a short explanation with Undo and 'Disable this
for me', which turns the preference off in place and confirms it. Saved layouts
should survive reload and reset when the tour revision changes."

---

## Update 1 — plan (2026-10-21)

"Planned as Phase 19 Wave 3 in `plans/PHASE-19.md`. One local preference schema
(`sothspell:canvas-preferences:v1`) for auto-zoom, auto-arrange, follow beat,
motion, contrast, palette, text scale, first-run flags, and saved layouts.
Auto-zoom frames source plus container; auto-arrange runs a deterministic
placement; both are undoable and honour reduced motion. Messages do not take
focus, pause on hover/focus, and remain available from the shortcut sheet. Test
defaults, persistence, invalid values, disable, undo, reduced motion, layout
restore, and revision reset."

## Fix
