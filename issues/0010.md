# "Canvas: incoming and outgoing containers with truthful flow links"

"Every code container needs Incoming and Outgoing toggle buttons. Turning one on
shows the code that calls the current symbol or the code it calls; turning it
off hides only the containers and links with no remaining active owner. The
canvas must show the relation kind and confidence, reuse existing containers,
and never cascade without a user action. A missing snapshot or source root must
disable the buttons with an explanation."
