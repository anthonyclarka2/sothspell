Embedding a Sóþspell tour

This static page is the Phase 16 docs fixture. It embeds the golden Bunbun tour with the custom element and with the iframe fallback, and it deliberately uses opinionated host CSS to prove the player cannot collide with a docs site.

Custom element

<sothspell-tour> renders in a shadow root and stores local progress under sothspell:embed:<tour>.

Iframe fallback

The same bundle runs inside embed.html and speaks the postMessage protocol.

Progress opt-out

The opt-out.html page in this fixture embeds the same tour with progress="off"; the browser test asserts that nothing is written to storage there.
